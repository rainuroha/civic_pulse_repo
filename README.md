# CivicPulse

CivicPulse is our Final Year Project (FYP) for community-based
road hazard reporting and visualization in Sukkur.

## Project Modules

- `mobile/` — React Native / Expo Android application
- `backend/` — FastAPI server and database integration
- `dashboard/` — React web dashboard
- `docs/` — Project documentation and API specifications

## Technology Stack

- Mobile: React Native and Expo
- Backend: Python and FastAPI
- Database: PostgreSQL and PostGIS
- Dashboard: React
- Maps: OpenStreetMap / MapLibre

## Team Workflow

1. Pull the latest changes before starting work.
2. Work on your assigned module.
3. Test changes locally.
4. Commit changes with a clear message.
5. Push changes to GitHub and coordinate before merging.
